# 卢浮宫 v1 上馆 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 卢浮宫作为第三家馆上线(~18.5k 件),唯一代码变更 = 多 QID 收藏锚点(`collection_qids`)。

**Architecture:** 馆身份(`wikidata_qid`,用于建筑照 P18/intro 材料/对外把手)与收藏锚点(`collection_qids`,缺省回退单锚点)分离;SPARQL 的 `?item wdt:P195 wd:{museum}` 改 `VALUES ?mus` 多值。其余全走既有零代码配方(catalog→names Batch→images→intro→coverage-report)。

**Tech Stack:** Python/FastAPI、SQLAlchemy、WDQS SPARQL、OpenAI Batch API(已有 batch_names.py)、Cloudflare R2。

## Global Constraints

- 存量两馆(orsay/orangerie)不写 `collection_qids`,行为必须逐字不变(VALUES 单元素语义等价)
- v1 不碰 Joconde 142k → louvre 条目 `sources: [wikipedia]`、无 `joconde_museum`
- staging 只跑护栏内小样(`staging_limit` 仅 staging 生效,prod 一律全量);不跑全量、不为规模付 LLM 费
- prod 全量为纯数据操作,连跑+事后报账(用户已批);预算 <$40
- Python 过 black+isort(pre-commit 钩子自动);Conventional Commits;feature→staging→main

## CLI 真实形态(2026-07-25 对齐 onboard.py,防命令写错)

| 子命令 | flag | 护栏 |
|---|---|---|
| `catalog` | `--target` `--limit` `--source` | 无护栏(靠 `--limit`) |
| `names` | `--target` `--limit` `--allow-full` `--use-batch` `--batch-job` | staging_limit |
| `images` | `--target` `--limit` | 无护栏 |
| `intro` | `--target` `--force` | 无(整馆) |

> prod 命令**不需** `--allow-full`(护栏只在 `target==staging` 触发);`catalog`/`images`/`coverage-report` 也没有此 flag。

def test_multi_collection_qids_in_sparql(monkeypatch):
    # 多锚点(louvre):SPARQL 用 VALUES 带全部 collection_qids
    import dataclasses

    cfg = dataclasses.replace(CFG, collection_qids=["Q19675", "Q3044768"])
    src = WikidataSource()
    captured = {}

    def _capture(sparql):
        captured["q"] = sparql
        return []  # 空结果 → fetch 首页即停,不进第二页

    monkeypatch.setattr(src, "_run_query", _capture)
    list(src.fetch(cfg))
    assert "wd:Q19675 wd:Q3044768" in captured["q"]
    assert "wdt:P195 ?mus" in captured["q"]


def test_single_anchor_falls_back_to_wikidata_qid(monkeypatch):
    # 不配 collection_qids(存量馆)→ 回退单锚点,VALUES 单元素语义等价
    src = WikidataSource()

        captured["q"] = sparql
        return []

    monkeypatch.setattr(src, "_run_query", _capture)
    list(src.fetch(CFG))  # CFG 无 collection_qids
    assert "wd:Q23402" in captured["q"]
    assert "wdt:P195 ?mus" in captured["q"]
