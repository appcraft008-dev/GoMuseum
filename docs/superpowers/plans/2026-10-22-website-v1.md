# gomuseum.app 网站 v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 gomuseum.app 做成由后端现生成的十语网站(首页/城市/馆/作者/作品页 + 试听 + sitemap + 自记统计),取代现静态首页与分享页展示。

**Architecture:** 在现有 FastAPI 后端新增「公开网页层」:数据读取集中在 `app/services/website/`(只读已发布内容、走可见性闸、不点火),路由在 `app/api/web/site_pages.py`,页面用 Jinja2 模板服务端出完整 HTML,交互(手风琴、连播、跟随)用一个原生 JS 文件。宿主机 nginx 把语言目录、sitemap、robots、`/w/` 反代到后端。

**Tech Stack:** Python 3.13 / FastAPI / SQLAlchemy / Jinja2(显式加依赖)/ 原生 JS + CSS / pytest(sqlite 内存库,同 `tests/integration/test_share.py`)。

**Spec:** `docs/superpowers/specs/2026-10-22-website-v1-design.md`(用户 2026-10-22 批准)。执行者两份都读。

## Global Constraints

- 语言代码固定十个:`en fr zh zh-hant de es it pl ja ko`;网址 `/{lang}/…`;`/` 由 nginx 301 到 `/en/`,hreflang `x-default` = `/en/` 对应页。
- 网页层**不带身份、不调内容接口路由、不触发任何生成**(不调用 `enrichment.lazy` 的点火函数、不调 TTS);只读 `status="published"` 且正文非空的内容。
- 馆/作品可见性一律 `museum_visible(db, slug, preview=False)` / `visible_museum_ids(db, preview=False)`;隐身馆在任何页面、sitemap、搜索结果、作者页里都不出现。
- 非试听作品**一个字节音频都不给**(不出现音频地址、不出现可推测的音频端点参数);试听音频只经 `/w/audio/…` 签发 1 小时 R2 预签名地址。
- 不写死馆名、馆数、城市名;十语馆名/城市名只经 `museum_repo.museum_names()` / `museum_cities()`。
- 统计全部写 `app_events`(`log_event`),不设 cookie、不用 localStorage/sessionStorage、不用任何第三方统计脚本。
- Play 链接只在 `settings.SHARE_PLAY_LIVE` 为真时输出;链接带 `referrer=utm_source%3Dgomuseum.app%26utm_medium%3Dweb%26utm_content%3D<page_type>`。
- 手机 / 平板竖 / 平板横 / 电脑四种宽度(390 / 820 / 1180 / 1440 px)无横向溢出、无重叠、无截断;不依赖 hover;平板竖屏走单列,≥1024px 走左右两栏。
- 薄页门槛:馆页/城市页某语言有发布 guide 的作品 <20 件、作者页 <3 件 → `noindex`,不进 sitemap、不进其他页的 hreflang(页面本身仍可打开)。
- 作品页段落顺序:导览 → 关于作者 → 各深度段(按 `category_sections.sort_order`)→ 常见问题(每问一条)。
- 新增带 `slug/qid/museum/museum_slug` 参数的路由必须登记 `tests/unit/api/test_visibility_routes.py::REGISTRY`。
- 前端契约(`/api/v1/...`)零改动;`recognition_succeeded` 只加 `qid` 属性(加法)。
- 提交信息 Conventional Commits,结尾带会话要求的 Co-Authored-By / Claude-Session 两行。

## Review Focus

1. **某作品只有部分语言有正文**:`/fr/…/{qid}/` 在 fr 无已发布 guide 时应 404(同现分享页的 noindex 404),且 hreflang、馆页列表、sitemap 都不链向它 → Task 6、Task 7、Task 8 各有测试。
2. **隐身馆从侧门漏出**:作者页(城市×作者跨馆汇总)、站内搜索结果、sitemap、首页馆标签 → Task 3、Task 6、Task 8 测试用隐身馆 `rijks` 的同名作者/同 qid 断言不出现。
3. **音频端点被枚举**:对非试听作品、隐身馆、不存在的段、试听名单外的语言请求 `/w/audio/…` 一律 404 且响应体相同 → Task 4 测试。
4. **旧分享链接**:`/a/{slug}/{qid}?lang=xx&s=wa` 在 xx 无正文、qid 不存在、馆隐身时的行为与现在一致(404 noindex),有正文时 301 且保留 `s` → Task 8 测试。
5. **超长/超宽内容在窄屏**:德语长标题、CJK 无空格长串、超宽横幅图(《梅杜萨之筏》Q212616)在 390/820px 下不溢出 → Task 10 截图检查清单逐项列出。
