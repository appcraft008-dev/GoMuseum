# 方案 B:无图作品不对用户开放 设计

日期:2026-10-11 · 状态:方向已获用户确认(10-11),**在方案 A 合并后另开分支**,开工前再细化实施计划
姊妹方案:[方案 A 懒生成防刷](2026-10-11-lazy-gen-abuse-guard-design.md)

## 一、起因(讨论经过)

1. 起点是接地闸的外观描写盲区:材料里没有视觉信息时,模型编「色调沉静/背景暗淡」,闸判 IMPRESSION 放行
   (记忆 `grounding-gate-visual-description-blindspot`)。有本地图的件生成前会先看图(gpt-4o),没图的件没有。
2. 先想的修法是"没图不写外观段、照片到了补写",以及"主讲解没图时换结构"(v4 试过加禁令无效,根因是第 2 拍
   "指出画面细节"这个结构指令本身)。
3. 用户指出:探索列表只显示有图件(`has_image_clause`)。核查后发现搜索、识别(文字链)、直接按 qid 请求
   仍能到达无图件。
4. 用户进一步问:向用户开放无图作品到底有多大价值?prod 数据(10-11 只读查询):

| 指标 | 数值 |
|---|---|
| 已上线馆无图件 | 卢浮 6892(40%)/ 奥赛 4708(69%)/ 小皇宫 319 / 橘园 23 |
| 识别最终确认成无图件 | 15 次:运营账号 12、7 月匿名测试 3,**真实用户 0** |
| 文字链候选卡里 top1 是无图件 | 313 次中 116 次(37%)—— 用户看不到图、无法对照 |
| 懒生成过的无图件 | 12 件(全部无看图描述),其中 8 件已录音频 44 段 |
| 照片反馈 | 81 条全是运营账号测试,**状态全是 new,无人处理**;90 天后自动删 |

5. 结论(用户定):**目录尽量收全,对用户只开放有图的作品**;照片补上后自动出现。
   顺带三件事:建新馆拉全量目录;每月扫一次授权图(用户拍到的优先);照片反馈要有人处理。
   用户照片继续只当线索,不当展示图(版权/隐私/质量,且隐私政策按"只作诊断、90 天删"填报)。

## 二、规则

**"有图"口径 = `must_see.has_image_clause`**(本地图或外链图,非隔离)。与探索列表同一个函数,规则只有一处。

| 入口 | 改成 |
|---|---|
| 识别:向量直判 / 候选 | 向量索引本来只有有图件,不变 |
| 识别:文字链(AI 读图 / 墙签)直判与候选 | 过滤无图件;过滤后没有候选 → `unrecognized`,走现有「都不是」流程 |
| 搜索 | 不返回无图件(**例外待定**:用户在「都不是」后按编号/名称精确搜,见第五节) |
| 懒生成 / 懒翻译 | 无图件不点火 |
| 内容 / 音频接口 | **照常返回**已有内容,不 404(老 App、足迹、分享链接不崩) |
| 老版完整馆包 `artworks=True` | 过滤无图件(形状不变,只少元素) |
| 照片补上之后 | 自动出现(判据实时,无需手动) |

**契约**:全部是"少返回一些元素",不改字段、不删字段 → 前向兼容,不用发包。

## 三、记录"用户拍到了但我们没图"

文字链匹配仍在全量作品上算,只是不给用户看。若被过滤掉的无图件本来会进直判或候选:
- 写进 `recognition_events.text_trace.hidden_imageless`(qid + 分数);
- 用户随后发照片反馈时,`server_result` 里已带这份信息。

用途:形成"用户在馆里拍到、我们没图"的清单 → 每月补图时优先找这些。

## 四、懒生成先物化图片再生成

现状:`maybe_trigger` 里补图(`run_lazy_images`)与生成并行跑 → 有外链图但还没下载到本地的件,
生成时看图那步拿不到图(`vision.primary_image_url` 只认本地图),照样写出没有视觉材料的讲解。
改为:同一个后台任务里**先物化图片,再生成**。物化失败 → 照常生成(行为同现状),不阻塞用户。

## 五、开工前要再定的

1. 「都不是」后按**馆藏编号精确搜**命中无图件时,要不要放行?(有说明牌作凭据,"无法对照"的问题不存在)
   默认:不放行,先只记录 `hidden_imageless`,有真实用户需求再开。
2. 已生成的 12 件无图件(8 件有音频):按规则从识别/搜索消失,内容保留,补上图后自动回来。

## 六、运营例行(写进 backlog,不是代码)

- **建新馆拉全量目录**:`onboard catalog` 不带 `--limit`;验收按"有图件"计已上线数。
- **每月 1 号扫授权图**:Wikidata 新 P18、小皇宫 P4765(CC0)、Paris Musées CC0 主图(S7 三条来源);
  `hidden_imageless` 清单优先。**由我在每月 1 号后的第一次会话里提醒,用户授权后再跑**,不设定时任务(用户额度常不足)。
- **每周处理照片反馈**:逐条标原因(没收录/没图/引擎认错/照片糊),没图的进补图清单,认错的进识别评测集。

## 七、不做

- 不用用户照片当展示图或识别底图(10-05 用户决定;要用需单独的授权勾选 + 改隐私政策)。
- 不再做"外观段等照片再写"和"主讲解无图换结构"—— 无图件不再生成,问题没有来源。
- 存量已生成内容不回刷。
