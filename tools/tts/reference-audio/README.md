# 参考音频（对标靶心，永久冻结）

两套基准，都是**判断新生成音频好不好的标尺**，不是生产内容。
所用文本统一为《草地上的午餐》（Q152509）的导览词，10 语见 `texts/`。

## `tts1_*.mp3` —— OpenAI tts-1 基准（10 语）

方法论的靶心。配方与 CLAUDE.md 都写着「**拿已接受的基准当靶心做全维度对标，
而不是自己拍阈值**」，说的就是这一套。

**不可再生**：付费 API 产出，且 tts-1 随时可能被 OpenAI 下架或改版。

> 教训（配方 §六）：曾自定 HNR≥15 的门槛，比 tts-1 自己（12–14.6）还严，
> 误杀了合格候选。**先量基准，再定阈值。**

## `FINAL_*.mp3` —— VoxCPM2 定稿基准批（10 语）

现行种子克隆出的定稿，**经用户耳朵逐条认可**。它承载的是听感判决，
重新生成得不到同一条（生成是随机的）。

用途是当**音色身份的靶心**：把候选音频与对应语言的 `FINAL_*` 做全维度指纹
比对，距离越近越贴近已认可的音色。2026-09-07 的英语种子实验证实
**这个距离能预测用户偏好，而锐度不能**（详见配方 §四）。
`tools/tts/../..` 下 `voice_fingerprint.py` 一类脚本仍在 `~/tts-lab`，未入库。

## 边界（重要）

**本目录只放永久冻结的参考物，不放生产音频。**
生产音频一律走 R2 对象存储（见配方 §二）。
往这里塞批量生成结果会让仓库不可控 —— 二进制进了 git 历史就删不掉。
